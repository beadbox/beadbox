## What's New in v0.29.3

One new bulk action from a community request, a fix found on the way, and a security update.

### Added

- **Set a status on every selected bead.** The selection bar has a Status control beside Archive. Its menu lists the same statuses as the detail panel, bd's built-ins and then your custom ones by name, and picking one writes it to every selected bead with one bd call each. "Closed" goes through bd's close, so a bead with an open blocker is refused with bd's own message and left as it was. A failure on one bead does not stop the others: one toast says how many were updated and names each failure with its reason, and only the failed rows stay selected, so a retry is one click. On full success the selection clears. The menu opens with Enter or Space, moves with the arrow keys and closes on Escape without writing.

### Fixed

- **Selection checkboxes in the flat table on desktop.** A workspace with no epics showed no checkboxes in its bead table in 0.29.2, so the selection bar could not be reached there. It now has them, as the mobile table already did.

### Security

- **Updater certificate checking.** rustls-webpki 0.103.16 and webpki-root-certs 1.0.10, the certificate verifier under the updater's downloads and, on Linux, its bundled root set, fixing two published advisories (RUSTSEC-2026-0382, RUSTSEC-2026-0383). No behaviour change.

### Under the hood

- Vite 8.1.6 (a development-server-only advisory; nothing from it ships), and a headless test harness that now checks the app's data paths on every push, and the updater's signature verification whenever the app's native code or its dependencies change.

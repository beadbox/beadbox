## What's New in v0.30.2

One fix, from a community report.

### Fixed

- **A Dolt server workspace added with a user other than root now connects as that user right away.** Before, it connected as root until Beadbox was restarted, and the workspace opened with "Access denied for user 'root'". A password saved before this update still works.

### From the community

Thanks to **[@op-fasc](https://github.com/op-fasc)** for the report (#62).

Requires the [beads](https://github.com/gastownhall/beads) CLI, version 1.1.0 or newer.

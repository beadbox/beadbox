## What's New in v0.30.1

Four fixes, two of them from the community, and a security update.

### Fixed

- **A failed save in the detail panel now says so and puts the old value back.** When the app lost contact with its background process while saving a field (a restart, or no reply in time), the panel kept the unsaved value on screen with a spinner that never ended and showed no error. Every detail-panel write, the tree's close, backlog, delete and archive actions, the formula pour, the custom-status save and the recovery screen's Fix button now treat a lost call as a failed save: an error toast and the previous value restored. Other tree changes reload the tree.
- **The Commands tab no longer shows a Dolt server workspace's password.** On the Activity page, the row for adding or re-authenticating a server workspace showed the call's arguments in full. Calls that carry a credential now show a single redacted placeholder in place of their arguments, and a test fails if a new call with a password-like parameter is not redacted.
- **Settings > Clear Cache keeps your analytics and automatic-update-check choices.** Clear Cache removed every saved preference, and both of those read as "on" when absent, so a user who had switched them off had them switched back on with nothing on screen saying so. The two choices are now kept; everything else Clear Cache resets is unchanged, and the Cache section says so.
- **The molecule graph's node tooltip shows bead titles, ids and statuses exactly as written.**

### Security

- **Dependency updates** for four published advisories: dompurify, which ships in the app through the analytics library, plus three development-only tools (happy-dom, zod, undici). The router packages move to their current matched set. No behaviour change.

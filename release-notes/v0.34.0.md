## What's New in v0.34.0

Filter by label, point Beadbox at the bd you actually use, and a lighter board under live changes.

### Added

- **Filter beads by label.** A label filter sits beside the status, type, priority, assignee and search filters and lists the labels bd knows for the workspace. Pick one or more and the list shows beads carrying any of them; parents of matching beads stay visible for context. It works in Beads, Chart and All projects, persists like the other filters, and clears when you switch workspaces from Beads or Chart.
- **Beadbox finds bd installed through a version manager, and you can set the bd path yourself.** Automatic detection now checks the mise, asdf and Nix shim locations. In Settings and on the bd-missing and bd-too-old screens you can save the path to a specific bd executable, validated before it is accepted, with "Use automatic detection" to go back; the screen shows which bd is in use, and a BD_PATH environment override always wins and is shown as such.

### Fixed

- **Beadbox's status reads no longer trigger bd's auto-push.** Status, type, workspace summary, epic status and molecule progress reads now run read-only and sandboxed, so a refresh never pushes your Dolt remote, on every supported bd version. Writes are unchanged.
- **A busy board does less work per change.** Live refreshes are coalesced into one in flight plus one catch-up, nothing refreshes while the window is hidden, unchanged rows and unchanged markdown are reused instead of rebuilt, and the dev console no longer re-renders the board while it is closed. This reduces memory pressure on boards with many live changes.

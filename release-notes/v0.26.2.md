## What's New in v0.26.2

### Added

- **Formulas, for everyone.** The Formulas view is no longer behind a feature flag — open it from the header tab or with `Cmd`/`Ctrl`+`3`. It lists the formulas available in your workspace and draws each one's steps as a graph, so you can see the shape of a workflow before you pour it. If you have never seen this view before, that is why: the flag defaulted off, and it often stayed off even when it was meant to be on.

Everything else in this release is build and documentation work with no user-visible effect.

### Known issue

**A formula that declares no variables will crash Beadbox.** Formulas with one or more variables are unaffected — the trigger is specifically an empty or missing variables table.

It takes out the whole window rather than just the Formulas view: opening the Formulas tab replaces the app with "Something went wrong!" — you do not need to click the formula for it to happen. Click **Show Error** — if it mentions `Object.keys(q.vars)`, this is the bug described here. Quit and relaunch Beadbox and it opens on your Beads view as normal; the rest of the app is unaffected. Only the Formulas tab is out of reach, and it will crash again each time you open it until the formula file is removed.

To get unstuck, delete that formula file. Formula files live in a `.beads/formulas` folder — the one inside your project, or the one in your home directory — and each is named after its formula, so the right file should be recognisable:

```
<your project>/.beads/formulas/<name>.formula.toml
~/.beads/formulas/<name>.formula.toml
```

If it is in neither place, this finds it wherever it is:

```
find ~ -name '*.formula.toml'
```

Delete it rather than moving it elsewhere — Beadbox looks for formulas in several places, so a file tucked into another one of them will keep crashing the app. Beadbox starts normally again once it is gone.

A fix is on the way. This is reachable at all because this release makes Formulas available to everyone, which is why it is here rather than in a footnote.

Available for macOS (Apple Silicon) and Linux (.deb).

Requires the [beads](https://github.com/gastownhall/beads) CLI, version 1.0.1 or newer.
